# IP Geo Checker

REST API для определения города по IP адресу с использованием нескольких геолокационных сервисов.

## Архитектура проекта

Проект следует лучшим практикам Go и использует многослойную архитектуру:

```
ip-geo-checker/
├── cmd/
│   └── server/          # Точка входа приложения
│       └── main.go      # Инициализация зависимостей и запуск сервера
├── internal/            # Внутренние пакеты (не импортируются извне)
│   ├── models/         # Модели данных (DTO)
│   ├── handler/        # HTTP обработчики (тонкий слой)
│   ├── service/        # Бизнес-логика
│   ├── repository/     # Работа с хранилищами (кэш, статистика)
│   └── geo/            # Клиенты для геолокационных API
└── go.mod
```

### Слои архитектуры

1. **Handler** (`internal/handler`) - HTTP обработчики
   - Тонкий слой, только валидация HTTP запросов
   - Вызывает методы сервиса
   - Обрабатывает HTTP ошибки

2. **Service** (`internal/service`) - Бизнес-логика
   - Содержит всю бизнес-логику приложения
   - Не зависит от HTTP
   - Использует интерфейсы repository и geo

3. **Repository** (`internal/repository`) - Хранилища данных
   - Интерфейсы для работы с кэшем и статистикой
   - Реализации: InMemoryCache, InMemoryStats
   - Легко заменить на Redis, PostgreSQL и т.д.

4. **Geo** (`internal/geo`) - Клиенты внешних API
   - Интерфейс Client для работы с геолокационными API
   - Реализация MultiAPIClient для параллельных запросов
   - Легко добавить новые API или моки для тестов

5. **Models** (`internal/models`) - Модели данных
   - Структуры для запросов и ответов
   - Не содержат бизнес-логики

### Принципы проектирования

- **Dependency Injection** - зависимости передаются через конструкторы
- **Интерфейсы** - используются для абстракции и тестируемости
- **Разделение ответственности** - каждый слой отвечает за свою область
- **Чистая архитектура** - внутренние слои не зависят от внешних

## API Endpoints

### POST /check_ip

Проверяет IP адрес и возвращает информацию о городе.

**Запрос:**
```json
{
  "ip": "8.8.8.8"
}
```

**Ответ:**
```json
{
  "city": "Mountain View (60%), Ashburn (40%)",
  "from_cache": false
}
```

### GET /get_stats

Возвращает статистику работы API.

**Ответ:**
```json
{
  "requests_count": 123,
  "cache_count": 10,
  "external_successful_requests_count": 534
}
```

## Запуск

```bash
go run cmd/server/main.go
```

Или скомпилировать:

```bash
go build -o ip-geo-checker cmd/server/main.go
./ip-geo-checker
```
